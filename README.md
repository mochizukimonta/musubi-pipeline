サーバーもクラウド契約もなしに、数人の Blender 制作チームが同じプロジェクト
フォルダを共有して作業するためのアドオンです。ファイルの転送そのものは
[Syncthing](https://syncthing.net/) に任せ、このアドオンは
**「本当に全員のファイルが一致しているか」を SHA-256 で検証する側**に徹します。

そのうえに、制作を回すための層が乗っています — 保存するたびの自動履歴、
同時編集を防ぐロック、シーン×カットの進行ボード、レンダー設定の共有、
保存時の品質チェック。

## 何を解決するのか

チーム制作で実際に事故が起きるのは、だいたい次の4か所です。

- **ファイルが全員に行き渡っていない。** 共有フォルダは「同期済み」と
  言うだけで、中身が本当に同じかは教えてくれない。→ 全ファイルの SHA-256
  照合リストを端末ごとに書き出し、突き合わせて
  **一致 / 未到達 / 差分 / こちらのみ**を報告します
- **2人が同じカットを同時に編集して片方の作業が消える。** → `.blend` を
  開いた瞬間にロックが付き、他の人が開くと警告が出ます
- **`c01_v002_final_final.blend` が増殖する。** → 保存するだけで履歴に
  退避されます。ファイル名で管理する必要がありません
- **誰がどこまで進んでいるか分からない。** → 進行ボードが全端末で共有され、
  Blender を持たない人向けに HTML でも書き出せます

## 動作環境

| | |
|---|---|
| Blender | 4.2 以降 |
| OS | **Syncthing の自動導入は Windows のみ。** バージョン管理・進行ボード・品質チェック・レビューは macOS / Linux でも動きます(Syncthing を自分で用意すれば同期検証も動きます) |
| 追加インストール | **不要。** Syncthing は公式 GitHub リリースから SHA-256 検証つきで自動取得します |
| UI 言語 | 日本語のみ |

## インストール

1. [Releases](https://github.com/mochizukimonta/musubi-pipeline/releases) から
   `musubi_pipeline-x.y.z.zip` をダウンロード
2. Blender のウィンドウに zip をドラッグ&ドロップ
   (または `編集 > プリファレンス > アドオン > ディスクからインストール`)
3. 3D ビューポートのサイドバー(`N` キー)に **Musubi** タブが出ます

## 最短の使い方

**立ち上げる人(1回だけ)**

1. `Musubi` タブの「ルート」にプロジェクト用フォルダを指定
2. **フォルダ構造を作成** — 映像制作 / アセット制作 / 最小構成 から選ぶ
3. **① 同期を始める** — 招待ファイルがルート直下に書き出されます
4. 招待ファイルをメンバーに渡す
5. 参加申請が来たら、**デバイスID を本人に確認してから**承認

**参加する人(1回だけ)**

1. 空のフォルダを作って「ルート」に指定
2. **① 招待ファイルで参加** — もらったファイルを選ぶだけ。同期IDの入力は不要
3. 承認されるとファイルが流れ込んできます

**それ以降**

普通に `Ctrl+S` で保存してください。履歴・ロック・進捗の更新は自動です。
新しいカットを始めるときだけ、シーン/カット番号を入れて
「カットとして配置保存」を押します。

## 設計上の約束

このアドオンが守っている制約です。機能を足すときもここは崩しません。

- **クリエイターの作業を妨げない。** 常駐スレッド・常設タイマーを持たず、
  状態取得は「開いた時 / 保存した時 / ボタンを押した時」だけ。
  保存処理そのものを遅らせません
- **同期プロトコルを自作しない。** 暗号・鍵交換・NAT越えを独自実装すれば
  脆弱性がほぼ確実に入ります。そこは Syncthing に委任します
- **同期フォルダに秘密を書かない。** API キーは同期対象外のローカル領域に
  置きます
- **同期フォルダを信頼しない。** 他人が書き込めるフォルダなので、そこから
  読むものは検証します(パス検証・HTML の全エスケープ・実行形式の混入検出)
- **自動で修正しない。** 品質チェックは赤く警告するだけで、保存を止めず、
  勝手に直しません。修正は確認付きの明示ボタンだけです

## 開発

```bash
python -m pip install pytest
python -m pytest              # 98テスト。Blender は不要です
```

テストは `bpy` に依存しない層(`core` / `sync` / `versions` / `tasks` /
`syncthing`)を素の Python で検証します。詳しくは
[CONTRIBUTING.md](CONTRIBUTING.md) と [tests/README.md](tests/README.md)。

## 謝辞

同期の中核は [Syncthing](https://syncthing.net/) です。堅実な P2P 同期
実装を公開してくれていることに感謝します。このアドオンは Syncthing
プロジェクトとは無関係で、公式リリースのバイナリを利用しているだけです。
